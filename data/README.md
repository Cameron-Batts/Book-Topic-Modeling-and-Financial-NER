# Local data setup
Place `book.csv` and `all-data.csv` here before running.

Book CSV columns: `title`, `summary_name_removed` (16,559 rows in the supplied file). Financial CSV: headerless sentiment/text pairs, Latin-1 encoding (4,846 rows). Raw source data is excluded from the public package; retained name-reduced summaries may still contain names.

CMU Book Summary Dataset: https://www.cs.cmu.edu/~dbamman/booksummaries.html . Financial data citation: Malo et al. (2014), https://doi.org/10.1002/asi.23062 . Observe applicable attribution and redistribution terms.
